# Danny & Shafina — Royal Blue Vintage

Static wedding invitation website for GitHub Pages.

## Publishing

Set GitHub Pages source to **Deploy from a branch**, branch **main**, folder **/(root)**.

## Notes

- This is the V4 website. Several names, venue details, and schedule entries baked into the panel images are placeholders. Confirm them before sharing publicly.
- RSVP currently saves to the visitor’s browser only; it does not submit responses to the couple.
- Background music requires a `music.mp3` file, which is not included.
- The couple photograph and design assets are included.
