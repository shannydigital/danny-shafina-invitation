# Danny & Shafina — Royal Blue Vintage

Website jemputan digital untuk 26 Disember 2026. Dihoskan menggunakan GitHub Pages, bukan Ubuntu Server.

## Pemasangan GitHub Pages

1. Extract `danny-shafina-github-pages-ready.zip` yang disediakan dalam ChatGPT.
2. Upload **semua fail di dalam folder** ke root branch `main` melalui **Add file → Upload files** (bukan fail ZIP).
3. Settings → Pages → Build and deployment → **Deploy from a branch** → `main` → `/(root)` → Save.
4. Buka https://shannydigital.github.io/danny-shafina-invitation/
